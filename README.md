# Sofy Cares — Donation Platform

This project powers **Sofy Cares** — a donation platform supporting a social association dedicated to the dignified care of elders who have lost family support. The initiative operates under Sofy Cares, the main company providing elder care services.

- **Previous domain:** sofycares.app
- **New domain:** sofy-cares.ac

## Tech Stack

- **React** 19 with TypeScript
- **Vite** for development and builds
- **Tailwind CSS** for styling
- **React Router** for client-side routing

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linter
npm run lint
```
